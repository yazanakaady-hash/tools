TraceLab — A Local Workspace for Security Analysis and Reverse Engineering

TraceLab brings file inspection, memory analysis, network traffic analysis, and system monitoring into a single web dashboard. Designed for security researchers and students, it helps organize investigations and reduces the need to switch between separate tools.

Its analysis tools support unpacking layered files, examining memory for potential cryptographic material, reviewing PCAP captures, and identifying anti-debugging indicators. Additional utilities provide process monitoring, CPU and memory metrics, and file encryption and decryption using AES-GCM.

Built with Python, Flask, and JavaScript, TraceLab runs locally at 127.0.0.1:8787. The project includes synthetic test samples for exploring its workflows and practicing analysis techniques.

TraceLab supports investigation and learning. Findings require interpretation and validation; they do not establish whether a file is safe or malicious.

For authorized security research and education only.
